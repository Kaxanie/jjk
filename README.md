# JJK Action RPG Demo

A polished, high-level playable prototype of a JJK-inspired top-down action RPG with:

- Tile-based overworld traversal (hub/route/shrine)
- Real-time combat (light/heavy, dodge i-frames, techniques)
- CE resource economy + cooldowns
- Summon command and affinity interactions
- Domain Expansion ultimate state
- Rank progression gate (F -> E unlock)

## Run

Open `index.html` directly in a modern browser, or run a local static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
